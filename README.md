# 写真ていしゅつ　セットアップ手順

児童が写真を3枚送り、先生が番号順の一覧を印刷するサイトです（Firestore だけを使い、Storage は使いません）。

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 児童ページ（クラス → 出席番号 → 写真3枚 → 送る） |
| `sensei.html` | 先生ページ（パスワードで開く・未提出の確認・印刷・全データ削除） |
| `common.js` | 設定（Firebase・先生のメール・クラスと人数）と共通の処理 |
| `firestore.rules` | Firestore のセキュリティルール |

Firebase を設定する前は「デモモード」で動きます。写真はその端末の中だけに保存され、先生ページのパスワードは何を入れても開きます。

## ステップ1：Firebaseプロジェクトを作る
1. https://console.firebase.google.com/ →「プロジェクトを作成」（Googleアナリティクスはオフでよい）
2. 「構築」→「Firestore Database」→「データベースを作成」
   - ロケーション：`asia-northeast1（東京）`
   - 「本番環境モード」で開始
3. 「ルール」タブに `firestore.rules` の中身を貼って「公開」

## ステップ2：先生のログインを作る
1. 「構築」→「Authentication」→「始める」
2. 「Sign-in method」で「メール / パスワード」を有効にする
3. 「Users」→「ユーザーを追加」
   - メール：`sensei@example.com`（実在しなくてよい。変えるなら `common.js` と `firestore.rules` の2か所も同じにする）
   - パスワード：先生ページで入れるパスワード（6文字以上）
4. （おすすめ）「Settings」→「ユーザーアクション」→「作成（登録）を有効にする」のチェックを外す

## ステップ3：設定を common.js に貼る
1. プロジェクトの設定（歯車）→「マイアプリ」→ ウェブアプリ（</>）を追加
2. 表示される `firebaseConfig` の中身を、`common.js` の一番上の `firebaseConfig` に貼る

## ステップ4：GitHub Pages に置く
- 例：`https://kyouzai-lab.github.io/shashin-teishutsu/`（児童用）
- 先生用は `https://kyouzai-lab.github.io/shashin-teishutsu/sensei.html`（児童ページからはリンクしていない）

## 使い方
- **児童**：クラス・番号を選び、写真を1〜3枚選ぶ → 「送る」。同じ番号でもう一度送ると、前の写真と入れかわる（前が3枚で今回1枚なら、1枚だけになる）
  - 選んだ写真は右上の × で取り消せる
  - 使わない枠は「空の写真」（0バイト）で上書きして、前の写真が残らないようにしている
  - 写真は送る前に、長辺1200px・600KB以下のJPEGに縮める
  - 写真を選ぶ画面でまとめて3枚選ぶと、1→2→3の枠に順番に入る
  - クラスと番号はその端末に記憶されるので、次回はえらび直さなくてよい
- **先生**：クラスのタブを切りかえる。上に未提出の番号が出る
  - 「印刷」→ A4横・1ページ2人（番号と写真3枚）。未提出の人は詰めて印刷される。1〜2枚の人は左に詰めて同じ大きさで印刷される
  - 印刷の設定は「余白：デフォルト」「倍率：100%」。PC の Chrome がおすすめ
  - 課題が終わったら、ページの一番下の「全データ削除」（「さくじょ」と入力すると消せる）

## 変えたいとき（common.js）
- クラスや人数：`CLASSES`（クラス名は「6-1」のような 数字-数字 の形）
- 1ページの人数：`PER_PAGE`
- 番号はルールで1〜40まで受けつける

## 注意
- 番号のなりすまし（ほかの人の番号で送る）は防げません。送る前に「この番号で送ります」と確認が出ます
- 無料プラン（Spark）の範囲：1人3枚×46人でだいたい20〜40MB。保存1GBまで・読み取り1日5万回までなので余裕あり
